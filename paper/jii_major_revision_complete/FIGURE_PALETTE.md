# AAF semantic figure palette

- AAF: `#006D77` deep teal
- PPO-only: `#5C677D` slate
- Constrained PPO: `#3A86A8` muted blue
- Fair PPO: `#7A6F9B` muted purple
- Static Guard: `#9A8F7A` warm gray
- Secondary context/profile: `#C28E0E` muted amber
- Ink: `#263238`
- Grid: `#D9DEE3`

The same mapping is used in every quantitative chart. Attack fractions and evidence profiles use shades, markers, or line styles within these families. The architecture diagram uses matching tints.
